## طريقة الرفع على GitHub Pages

1. أنشئ مستودع جديد على GitHub باسم مثلاً `community-jordan` أو `generals-zh-jordan`
2. ارفع كل محتويات هذا المجلد (index.html + css + js + README)
3. روح إلى **Settings → Pages**
4. اختر Branch: `main` و Folder: `/ (root)`
5. احفظ وانتظر دقيقة، الموقع راح يكون على:
   `https://YOUR_USERNAME.github.io/REPO_NAME`

كل النصوص موجودة داخل `index.html` بشكل واضح.
